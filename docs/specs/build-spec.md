# WorldLibs build spec

Static site on Cloudflare Pages. No server, no database. The repo holds the
verified data; the build turns it into small static files; manuscript scans
stream live from the holding library's IIIF server.

Gap status lives in `data/planning-gaps.json` and Phase A acceptance in
`data/phase-a.json`. This file says how things are built, not whether they are done.

## Data files

Source of truth, in the repo:

| File | What it holds |
| --- | --- |
| `data/verify/*.json` | Evidence rows: facts, events, plans, books, corrections. Each row has `status` (passing or failing), `quote`, `source`, `tier` (primary, secondary, wikipedia) and the `check` that proves it. Schema in `data/verify/BRIEF.md`. |
| `data/libs.json` | 30 libraries: `id`, `n` name, `k` room kind (hall, dome, rotunda, atrium, site), `lat`/`lon`, `y`/`yl` year and label, `lost`, `found`, `st`/`stFrom` current status, `dim`, `vol`, `book`, `wd` Wikidata QID, `tier`, `phase`. A value ending in `*` has no passing row and must not ship. |
| `data/facts.json`, `data/books.json` | Generated by `merge.mjs` from `data/verify/`. Never edit by hand. |

Build output, in `dist/`:

- `dist/lib/{id}.json` is the library manifest, one per room, fetched when the room opens:
  ```json
  {
    "id": "longroom", "wd": "Q1319605", "name": "The Long Room",
    "facts": [{ "lib": "longroom", "field": "dims", "value": "length: 63.7 m", "tier": "primary", "source": "..." }],
    "hall": { "length": { "v": 63.7, "basis": "measured", "src": "..." } },
    "shelves": [{ "id": "dracula-se", "title": "Dracula", "tier": "readable-text" }],
    "credits": [{ "file": "...", "author": "...", "licence": "CC BY-SA 4.0", "url": "..." }]
  }
  ```
  `facts` copies passing rows only. A field with no passing row is left out, not guessed.
- `dist/book/{id}/meta.json` holds title, author, edition, licence, part count and table of contents.
- `dist/book/{id}/{n}.json` is one part of a text book, 200 KB at most:
  `{ "book": "dracula-se", "part": 3, "of": 9, "chapters": [{ "title": "...", "html": "..." }] }`.
  HTML is sanitised at build time down to `p`, `em`, `strong`, `blockquote`, `h2`-`h4` and `br`.
- `dist/book/{id}/pages.json` is a slim IIIF page list for scan books, built from the
  manifest so the client never downloads the full manifest:
  `{ "manifest": "...", "pages": [{ "s": "<image service base>", "w": 5000, "h": 7000, "l": "f. 1r" }] }`.

Wikidata is read at build time, never from the browser. Use a User-Agent with a
project URL and wait 1 s between requests.

## Hall kit

Most rooms have no published measured plan. Only the LoC Reading Room (1897
Handbook) and Celsus (published ground plan) do. Every other room is built from
one parametric hall kit fed with proven dimensions and licensed photos.

Parameters: `length`, `width`, `height`, `storeys`, `baysPerSide`, `alcoveDepth`,
`galleryHeight`, `vault` (barrel, dome, flat, coffered), `domes`, `windows`,
`shelfUnit` (width, shelves per unit), `wood`, `floor`, `light`.

Every parameter carries `{ v, basis, src }`. The basis is one of:

| basis | meaning | UI label |
| --- | --- | --- |
| `measured` | stated in a primary or secondary source | none |
| `photo-estimate` | scaled from licensed photos against a measured length | "estimated" |
| `excavated` | from an excavation report | none |
| `attested` | described in an ancient or period text | "described in sources" |
| `comparandum` | borrowed from a comparable surviving building | "based on [building]" |
| `invented` | design fill with no source | "reconstruction" |

Long Room example: length 63.7 m, width 12.2 m and height 14.2 m are `measured`.
`baysPerSide` and `galleryHeight` are `photo-estimate` until a source turns up.

## Delivery

- Host: Cloudflare Pages free plan. Limits: 20,000 files, 25 MiB per file, unlimited bandwidth.
- Budgets: 5 MB initial transfer, 25 MB per room, 200 KB per text part.
- Models are glTF with Meshopt geometry and KTX2 textures. Hashed file names.
- Service Worker:
  - hashed assets: cache-first, kept forever;
  - `dist/lib/*.json` and `meta.json`: stale-while-revalidate;
  - text parts: cache on first read.
- IndexedDB keeps opened books for offline re-reading. Call `navigator.storage.persist()` the first time someone opens a book.
- IIIF scans:
  - The turning page uses `/full/600,/0/default.jpg`. The Bodleian Folio measured 196 KB at 600w, against 541 KB at 1024w. WebP was larger, so stay on JPEG.
  - Zoom loads region tiles at 1536 px or more.
  - Prefetch two spreads either side of the open one.
- The page-turn reader is StPageFlip drawn onto a CanvasTexture. With reduced motion turned on, pages switch with a fade instead of a turn.

## Link check

Weekly scheduled job, plus a manual run before every deploy:

1. Run the `check` command on every row in `data/verify/` and record its status.
2. Send a HEAD request to every `read.url` and IIIF manifest.
3. A book whose reader URL fails drops to the `catalog` tier until it is fixed. A fact that fails disappears from the next build.
4. Write `data/link-check.json` holding the run date, each changed row and its old and new status.

Some hosts block scripted requests: loc.gov, Gallica, NYPL, lop.parl.ca, jhu.edu
and manuscripta.at. Their rows carry `"browser-only": true`. Re-prove them with
`scripts/ab-check.sh URL REGEX`, which opens headed Chrome and searches the
visible text. Run it outside any sandbox, because a sandboxed Chrome cannot
resolve hosts. Pages behind a CAPTCHA (loc.gov, Trinity) still need a person.

Gallica opens in a real browser, but its images do not load inside another
site. BnF books therefore stay catalogue cards with a link out to Gallica.

## Error reports

Every fact and book card has a "Report a mistake" link. It opens a pre-filled
GitHub issue holding the library id, field, value shown and source URL. There is
no form backend and nothing personal is collected. A fix lands as a new evidence
row with a quote in `data/verify/`, and `merge.mjs` regenerates the output.
Nobody edits generated files directly.

## Reconstruction

This covers lost libraries where no plan survives: Alexandria, Pergamon,
Nineveh, Herculaneum, Nalanda and the Corvina library at Buda.

- Evidence lives in `data/verify/recon-ancient.json` as rows with `field: "recon"`, an `element` (such as "reading room colonnade") and a `basis` (`excavated`, `attested`, `comparandum` or `invented`), plus the usual quote, source and check.
- AI may produce geometry and decoration from those rows: proportions, mouldings, shelving style, materials and lighting. AI never invents facts. Names, dates, numbers, holdings and events must come from a passing row.
- The room shows a permanent "Reconstruction" badge. Tapping any element shows its basis and source.
- An "Evidence" toggle tints the room by basis, so people can see how much is excavated and how much is invented.
- Stories the sources do not support appear on a labelled myth panel, never as facts. Examples: Alexandria lost in a single fire (the sources support damage in 48 BCE and an unknown end), and Nalanda burning for three months.

## Shelf policy

A book goes on a room's shelves only when a passing row ties it to that library.
General public-domain texts, and books held by institutions WorldLibs does not
model (the Voynich manuscript at the Beinecke, Codex Sinaiticus at the British
Library), go to a global reading list instead. They keep their `holder` field.
`merge.mjs` enforces this by setting `lib` to null for any library id missing
from `libs.json`.

## Licence

Code and data are MIT and open source (`LICENSE`). Texts and scans keep their
holders' licences. They load from the holder at read time and are never
committed. Most open manuscript scans (Bodleian, e-codices, Trinity) are CC
BY-NC, so the public site stays free, with no ads and no paid tier. A commercial
fork must drop those scans. A scan whose licence says permission is needed
(Vatican, Kells) stays a catalogue card even when its manifest loads; `merge.mjs`
enforces this in `tierOf`. The credits panel lists the author and licence of
every image it uses. The decision is recorded in `data/planning-gaps.json` under
`decisions.licence`.

## Globe

Source: `reports/WorldLibs realistic dynamic worlds.md`.

- Custom three.js globe, WebGLRenderer. Layers, bottom to top:
  - NASA Blue Marble day texture, 4k KTX2. Month follows the time slider's season.
  - NASA Black Marble city lights, 4k KTX2, multiplied by `(1 - day)`.
  - Day term: `smoothstep` of `dot(normal, sunDir)`. The sun position follows the same slider as the library timeline.
  - Ocean specular from a land mask, a small relief map, one drifting 2k cloud layer, a Fresnel atmosphere rim.
- Budget: `dist/globe` 4 MB or less. Credit NASA on the credits panel.
- Library pins read `{founded, destroyed}` from `libs.json`. A pin is ghosted when the slider sits outside that range.
- Picking a library flies along the great circle with a rise-then-drop height arc. The room manifest, lightmaps and atlases start downloading when the flight starts.
- The globe unrolls into the Equal Earth flat atlas through one morph uniform. The atlas is where people pick from the European cluster and from the list on phones.
- Deep zoom (later): OpenFreeMap vector tiles, or EOX Sentinel-2 cloudless (CC BY-NC-SA, loaded live, never bundled).
- Ancient coordinates come from Pleiades (CC BY). Historical borders are out of Phase A; when added, use OpenHistoricalMap (mostly CC0), not historical-basemaps (GPL-3.0).
- "See it today" (standing buildings, click to load): MapLibre GL JS with the OpenFreeMap Liberty style, whose `building-3d` layer raises OpenStreetMap buildings, on Mapterhorn terrain (AWS Terrain Tiles as fallback). All free with no key; all three allow cross-site fetches (tested 2026-11-08). MapLibre loads only on click. Attribution: "OpenFreeMap © OpenMapTiles Data from OpenStreetMap" (MapLibre adds it) and "© Mapterhorn". Interiors use Wikimedia Commons photos and panoramas, credited per file.
- Google Photorealistic 3D Tiles are out (owner, 2026-11-08): $6 per 1,000 root requests past 1,000 a month. No free photoreal global mesh exists, so the street view is honest blocks.

## Dynamic worlds

- Split the work:
  - Built on the visitor's device: hall shell, bays, shelves, books. A Web Worker runs a seeded PRNG over the hall-kit JSON (a few KB) and returns geometry buffers.
  - Baked at build time: lightmaps (three-gpu-pathtracer, three-mesh-bvh and xatlas; day and candle variants), shared wood, plaster and gilding atlases, a far-end impostor image, unique props, optional splat hero zone.
- One `InstancedMesh` per bay, 2 to 4 book geometries, spine titles from one atlas. Per-book colour, height and lean come from the seed.
- Load order: shell and impostor first, then bays nearest the camera. Hold the camera at the edge of an unbuilt bay (the Roblox `PauseOutsideLoadedArea` idea).
- Do not cache generated geometry; the same seed rebuilds it. Cache baked assets with hashed names.
- Cap the room cache at 8 rooms, oldest evicted first. Safari allows about 1 GB and evicts after 7 idle days; 30 rooms at 25 MB would be 750 MB.
- Splats: Spark 2.0 (MIT), `.RAD` or SPZ, about 500k splats on mobile. One hero zone or backdrop per room at most; walkable geometry stays mesh. Measure the file against the 25 MB room budget before adding it.
- AI at build time only:
  - Quote to parameters: an LLM proposes hall-kit JSON from cited quotes. A schema check runs, a script checks that each number appears in its quote, a person signs off, and the paradata is written. An element with no quote id gets basis `invented`.
  - Props from TRELLIS.2 (MIT) from a licensed reference photo, or a paid API after its output terms are read. Badge every AI asset with model and date.
  - World Labs Marble: one backdrop for one lost library at most, tagged `invented`, after the ToS check and a size test.
  - Not used: Genie 3 (no export), Hunyuan models (licence excludes the EU, UK and South Korea), Sketchfab models flagged NoAI.
- No AI-made text, faces or inscriptions anywhere.

## Living pages

- One shared component: predict, then reveal, then stamp. Each page is a single three.js or SVG scene that reuses it.
- Pilots:
  - Phase A: Byrne's Euclid (1847, public domain) in the Long Room.
  - Phase B: Plan of St Gall (Cod. Sang. 1092, CC BY-NC 4.0 on e-codices) in St Gallen; Darwin's divergence diagram.
- Budget: about 2 to 4 days per page once the component exists.
- Stamps are cosmetic, kept in `localStorage` under `wl.stamps`. No streaks, no leaderboards, no network calls.
- With reduced motion turned on, reveals cross-fade instead of animating.

## Performance

- First paint: a pre-rendered globe poster under 60 KB with `fetchpriority="high"`. It is the LCP element; canvas does not count for LCP.
- three.js and the globe load as one lazy chunk after the poster. Measure the gzip size of the real imports (GLTFLoader, KTX2Loader, Meshopt) on the current release (r187 on 2026-11-08).
- Renderer: WebGLRenderer. Try WebGPURenderer only behind a flag and an A/B frame-time test.
- Resolution: a governor lowers device pixel ratio when p95 frame time goes over 20 ms and raises it when it stays under 12 ms. Do not rely on detect-gpu tiers (its data stopped updating in December 2025).
- `_headers`: `Cache-Control: public, max-age=31536000, immutable` on hashed assets.
- Same-document View Transitions between globe, room and reader, with a plain cut when unsupported.
- Modes: guided tour, free roam, and a reader list with no 3D. With reduced motion turned on, fly-ins become cross-fades.
- CI gates: Lighthouse mobile LCP under 3 s and transfer 5 MB or less; Playwright p95 frame time 20 ms or less; `renderer.info` draw calls under 200 in the Long Room.
